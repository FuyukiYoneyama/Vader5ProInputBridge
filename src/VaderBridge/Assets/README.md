# Bridgeのアイコン

紺の角丸背景に、白いコントローラーとシアン（明るい青）の軌道線を配置した専用デザイン。小さい表示で操作機器を見分けられるよう、十字キーとボタンの形を太く描く。

`VADERBridge.ico`はEXE・状態画面・設定画面で使用する。ICO（Windows用の複数サイズ入りアイコンファイル）には16、20、24、32、40、48、64、128、256ピクセルを収録する。角丸の外側は透明。

通知領域には同じデザインに状態の印を付ける。

| ファイル | 状態の印 |
|---|---|
| Starting.ico | 青：初期化 |
| Ready.ico | 緑：使用可能 |
| Waiting.ico | 黄：待機・再接続 |
| Error.ico | 赤：エラー |

`VADERBridge.png`は大きい表示用、`preview.png`は各サイズと背景色の見え方をまとめた画像。

再生成はプロジェクト直下で次を実行する。Pillow（画像を生成するPythonライブラリ）を使用する。

```powershell
python .\tools\create-icons.py
```

形と配色の原本は`tools/create-icons.py`。アプリには生成したICOを埋め込み、同じ図案を使用する。

# VADER Bridge 1.0.7

HOME/Guideによる正面更新時のOpenTrack出力を修正した版です。

## 変更内容

- HOME/Guideを短押しして離した際に、OpenTrackへYaw・Pitch・Rollがすべて0°の値を優先送信します。
- 正面更新と送信を同期させ、リセット前の値が後から送られる経路を防ぎました。
- リセット時にBridgeの平滑化履歴をクリアし、通常の送信周期を待たずにゼロ値の送信を開始します。送信に失敗した場合も、成功するまでリセット要求を保持します。
- 配布ZIPの画像を利用ガイドで参照する設定画面3枚に限定し、配布物を軽量化しました。

## ダウンロードと更新

1. `VADERBridge-1.0.7.zip`と`VADERBridge-1.0.7.zip.sha256`を入手し、SHA-256を照合します。
2. 使用中のBridgeを通知領域のアイコンメニューから終了し、ZIPを新しい書込み可能なフォルダーへ展開します。
3. `VADERBridge.exe`を起動し、本体を約2秒静止させてから、使用する持ち方でHOMEを短く押して離します。
4. OpenTrackで追跡を開始し、姿勢角度と正面更新を確認します。

Windows x64、[.NET Desktop Runtime 10のx64版](https://dotnet.microsoft.com/en-us/download/dotnet/10.0)、[vJoy](https://github.com/BrunnerInnovation/vJoy/releases)、姿勢連携用の[OpenTrack](https://github.com/opentrack/opentrack/releases)が必要です。詳細な設定手順はZIP内の`利用ガイド.md`と[README](https://github.com/FuyukiYoneyama/Vader5ProInputBridge/blob/v1.0.7/README.md)を参照してください。

拡張入力取得中は、VADER側の仕様により標準XInput出力が停止します。Bridge側にXInputを停止させる処理を実装したものではありません。通常入力はvJoy 1経由で使用します。

## 配布内容

実行用ZIPにはアプリ、既定設定、利用ガイド、ライセンス、第三者の著作権表示、ファイル識別一覧を収録しています。ソースは`Vader5ProInputBridge-1.0.7-source.zip`からも入手できます。

配布EXEはコード署名していません。Windows SmartScreenで警告が表示される場合があります。入手元とSHA-256を確認してください。

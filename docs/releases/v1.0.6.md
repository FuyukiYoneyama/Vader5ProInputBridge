# VADER Bridge 1.0.6

VADER 5 Proの通常入力・追加ボタンをvJoyへ、姿勢角度をOpenTrackへ送るWindowsアプリの初回公開版です。

## 主な機能

- vJoy（仮想ゲームコントローラー）のDevice 1へ、スティック・独立トリガー・十字キー・20ボタンを出力。
- ジャイロと加速度から求めた姿勢角度をOpenTrackへ送信。HOME短押しで正面を更新。
- 起動時に取得と出力を自動開始し、通知領域（時計の横のアイコン欄）へ常駐。
- 入力と出力の固定表示、表示ON／OFF、一時停止／再開、必要な区間のログ採取。ログの初期値はOFF。
- 接続回復中は最終値を保持し、入力が復帰した後に更新を再開。

## ダウンロードと準備

1. このReleaseの`VADERBridge-1.0.6.zip`と`VADERBridge-1.0.6.zip.sha256`を入手します。
2. Windows x64（64ビット）に[.NET Desktop Runtime（Windowsアプリの実行環境）10のx64版](https://dotnet.microsoft.com/en-us/download/dotnet/10.0)、[vJoy](https://github.com/BrunnerInnovation/vJoy/releases)、姿勢連携用の[OpenTrack](https://github.com/opentrack/opentrack/releases)を用意します。
3. ZIPのSHA-256（ファイル内容の識別値）を同名`.sha256`と照合し、書込み可能なフォルダーへ展開します。
4. vJoyのDevice 1をX・Y・Z・Rx・Ry・Slider・Dial/Slider2、20ボタン、Continuous POV（角度で指定する十字キー）1個に設定します。
5. `VADERBridge.exe`を起動し、案内に従って本体を約2秒静止させ、HOMEを短く押して離します。
6. OpenTrackのInputを`UDP over network`、Portを`4242`に設定して追跡を開始します。ゲーム側ではvJoy 1のDirectInput（Windowsのゲームコントローラー読取り方式）を割り当てます。

詳細はZIP内の`利用ガイド.md`と、[README](https://github.com/FuyukiYoneyama/Vader5ProInputBridge/blob/v1.0.6/README.md)を参照してください。

## 動作条件

- 初期対象はUSB有線のVADER 5 Proです。vJoy 2への出力は既定でOFFです。
- （拡張入力取得中は、VADER側の仕様により標準XInput（Windows標準ゲームパッドの読取り方式）出力が停止します。BridgeにXInput出力を停止させる処理を実装したものではありません。）通常入力はvJoy 1経由で使用します。
- USB再接続後、安定まで約20～30秒かかる例があります。通知領域と状態画面で回復状況を確認できます。
- Yaw（左右方向の回転角）には角速度の積算による微小ドリフトがあり、HOME短押しで正面を更新できます。
- （配布EXEにはコード署名を付けていません。）Windows SmartScreenが警告を表示する場合があります。入手元のリポジトリとSHA-256を確認してください。
